One satirical sentence about a lawmaker who regulates AI but cannot convert a file to PDF, written by a small Python program.

> The senator who converted a swing district, three mega-donors, and an entire committee cannot convert a single .docx to PDF, so the bill that will govern artificial intelligence is, legally speaking, still a Word document.

## Run

```sh
python3 main.py
```

This writes the sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), 222 characters, no trailing newline.
